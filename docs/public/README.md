# jtcsv brand assets

This directory holds the canonical SVG brand-mark family for jtcsv. All assets are pure inline SVG with no external font URLs — the wordmark uses a system monospace stack (JetBrains Mono → DM Mono → Fira Code → ui-monospace → system fallbacks) so social-card unfurls render correctly even when webfonts are blocked. The palette is locked: primary teal `#0EA5A4`, primary-dark `#0F766E`, ink `#0F172A`. Do not introduce TypeScript-blue or shields-green here.

Pick the right asset by use case. `logo.svg` (64×64) is the standalone mark — favicon SVG, README hero, anywhere the bare mark is wanted on a light background. `favicon.svg` (32×32 viewBox) is the same mark re-fit to small pixel grids; wire it from `<link rel="icon" type="image/svg+xml" href="/favicon.svg">`. `logo-wordmark.svg` (360×72) is the horizontal lockup — mark plus the "jtcsv" wordmark in monospace; use this in docs headers, nav bars, and GitHub README hero strips. `brand-mark.svg` is the inverse (teal-on-white) variant of the mark — use on dark hero strips or above the gradient OG background.

`og-image.svg` (1200×630) is the social-share card consumed by npm, GitHub, Twitter/X, and OpenGraph unfurls. It carries the title, the one-line elevator pitch, and three "pillar" chips (`~18 KB gz`, `Zero runtime deps`, `CSV injection guard by default`). If you change tagline copy or pillar numbers, update this file too — it is the public face of the package. Keep all files small: every byte counts for unfurl latency, and the og-image in particular is fetched by every link preview.
